# License Status

W6PS SatRotor is not yet published with a final open-source license.

## Current Position

- the project is being organized as if it may go to GitHub
- the final public licensing decision is still pending
- no GPL code should be copied into this repository

## What Is Allowed Internally

- studying other open-source rotator projects for protocol behavior
- taking notes on interoperability expectations
- using public documentation and observed behavior to design our own implementation

## What Is Not Intended

- copy/pasting GPL source into W6PS SatRotor
- quietly inheriting GPL obligations by mixing code without making an explicit decision

## Future Decision

When the project is closer to public release, this file should be replaced or
supplemented with the actual chosen license.
